# FlowScope React Demo

Interactive MVP demo for FlowScope, focused on healthy team visibility instead of toxic KPI tracking.

Live demo:
[https://tr-dark.github.io/flowscope-react-demo/](https://tr-dark.github.io/flowscope-react-demo/)

## What is included

- React + Vite demo app
- product walkthrough across Integrations, Surveys, Teams, Insights, and Governance
- mock data that simulates an internal workspace experience
- UI interactions for syncing, survey editing, previews, and action tracking

## Project structure

- `flowscope-react-demo/` - main React application
- `demo-app/` - older static demo version
- `notes/` - product and demo planning notes

## Run locally

```bash
cd flowscope-react-demo
npm install
npm run dev
```

## Build

```bash
cd flowscope-react-demo
npm run build
```

## Current scope

This version is still frontend-only and uses mock data. The goal is to validate product flow, screen structure, and interaction ideas before adding a backend or real integrations.
